# SQL and pandas, side by side (pharma data)

I am learning SQL and pandas together by answering the same questions in both tools
and comparing the results.

**Data:** a small sample of the FDA Drugs@FDA public data: 360 drug applications from 12 sponsors,
their 599 products and 2,526 regulatory submissions. Source:
https://www.fda.gov/drugs/drug-approvals-and-databases/drugsfda-data-files
